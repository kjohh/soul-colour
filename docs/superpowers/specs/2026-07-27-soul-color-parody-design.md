# 靈魂顏色偵測儀 — 設計文件

日期：2026-07-27

## 背景

惡搞近期 YouTuber 錫蘭踢爆 Jolie 販售「靈魂顏色拍攝」的時事。做一個純靜態網頁版，
讓使用者體驗這種「煞有其事、其實是亂數」的靈魂顏色偵測，最後產出一張可下載的拍立得。
專案將部署到 GitHub Pages。

## 核心設計原則

- **簡潔、療癒、精緻**：留白充足、動作輕柔、質感細膩。
- **不使用 emoji**。
- **不使用模板感卡片**（例如左側有色條 / 彩色 ribbon 的那種卡片）。
- 深色、神秘、極光漸層的視覺基調。
- **手機優先**（直式），因為需要前鏡頭自拍 + 食指按壓。
- 笑點在於：介面演得很認真地「讀取靈魂能量」，但顏色其實完全隨機。

## 技術方案

- 純 vanilla **HTML / CSS / JS 單頁**，無框架、無打包步驟。
- 相機：瀏覽器原生 `getUserMedia`（預設前鏡頭 `facingMode: "user"`）。
- 合成與下載：`<canvas>` + `toBlob` 產生 PNG。
- 直接放 repo 根目錄，GitHub Pages 指向 main 分支即可運作。

## 使用者流程（單頁，狀態切換）

以單一頁面切換四個狀態，不換路由。

1. **開場（intro）**
   - 半正經半唬爛的標題（暫定「靈魂顏色偵測儀」，實作時可再定）。
   - 一句簡短引導文案。
   - 「開始偵測」按鈕。

2. **相機（camera）**
   - 全螢幕前鏡頭預覽。
   - 底部一顆大快門鈕。按下 → 定格當下畫面（存成影像資料）。
   - **退路**：若無相機權限或裝置無鏡頭，改提供「上傳一張照片」，後續流程相同。

3. **按壓讀取（reading）**
   - 定格的照片作為背景。
   - 正中央一顆圓形按鈕，提示「請用食指按住」。
   - 按住時：按鈕周圍出現**極光光暈 + 多色漸層**，緩慢旋轉／擴散；中央顯示能量讀取進度，約 2–3 秒。
   - 若中途放開 → 進度歸零、需重新按住（強化儀式感）。
   - 進度完成 → 進入結果狀態。

4. **結果（result）**
   - 在拍到的照片上疊一層**隨機生成的漸層色**（半透明混色，營造沖洗出的顏色感）。
   - 套上**拍立得白框**。
   - 「下載」按鈕（輸出 PNG）＋「再測一次」（回到開場或相機）。

## 隨機漸層邏輯

- 每次隨機挑 2–3 個色相，組成線性漸層，搭配隨機角度。
- 疊在照片上時使用適當的混合模式（如 `mix-blend-mode`），讓顏色像是沖洗顯影出來的，而非生硬覆蓋。
- 完全由亂數決定，與照片內容無關——這正是惡搞的核心。

## 下載合成

- 用離螢幕 `<canvas>` 依序繪製：照片 → 漸層覆蓋層 → 拍立得白框。
- `canvas.toBlob()` 產生 PNG，觸發下載。
- 輸出比例維持拍立得長寬感（照片方形 + 下方較寬白邊）。

## 元件邊界

- **相機模組**：負責取得串流、拍照定格、無權限時的上傳退路。輸出：一張影像。
- **按壓讀取模組**：處理 pointer 按住/放開、進度與極光動畫。輸出：完成事件。
- **合成模組**：輸入影像 + 隨機漸層設定，輸出拍立得影像（給預覽與下載共用）。
- **狀態控制**：管理四個狀態間的切換。

各模組透過明確的輸入/輸出溝通，可獨立理解與調整。

## 非目標（YAGNI）

- 不做靈魂解讀文字。
- 不做後端、不儲存任何資料、不上傳照片到伺服器（純前端、隱私友善）。
- 不做多語系（僅繁體中文）。
- 不做帳號、分享後端。
