# 靈魂顏色偵測儀

一個純前端的惡搞小網頁：讓儀器「讀取」你此刻散發的靈魂顏色，最後生成一張可下載的拍立得。

> 靈感來自 YouTuber 錫蘭踢爆某販售「靈魂顏色拍攝」的時事。這個網頁把那套儀式感完整還原——介面演得煞有其事，但**顏色其實完全是亂數**。純娛樂，請勿當真。

## 玩法

1. 按下「開始偵測」，允許使用相機（或改為上傳一張照片）
2. 拍下一張照片
3. 用食指按住中央的能量球，感受極光光暈從指尖擴散、緩緩波動
4. 讀取完成，得到一張蓋上靈魂色的拍立得
5. 下載保存，或再測一次

## 特色

- **完全在裝置端運算**，不會上傳任何影像，隱私友善
- 隨機生成的極光漸層——每次都不一樣
- 拍立得質感：紙質顆粒、投影、照片暗角
- 手機優先，直式體驗
- 無框架、無打包，三個檔案就能跑

## 本機執行

因為用到相機，必須在 `localhost` 或 HTTPS 下才能取得鏡頭權限（直接用 `file://` 開只能走上傳）。

```bash
# 在專案根目錄啟動任意靜態伺服器，例如：
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 部署到 GitHub Pages

推上 GitHub 後，到 repo 的 **Settings → Pages**，將 Source 設為 `main` 分支的根目錄（`/root`）即可。網站會是 HTTPS，相機可正常使用。

## 技術

- 原生 HTML / CSS / JavaScript，無相依套件
- 相機：`getUserMedia`
- 合成與下載：`<canvas>` + `toBlob`

## 檔案結構

```
index.html    介面結構與四個畫面（開場 / 相機 / 按壓 / 結果）
style.css     視覺樣式與動畫
app.js        流程控制、相機、按壓讀取、隨機漸層、拍立得合成
```
